## Local LLM

Models and creative tools that run on your own machine.

### [Qwen-Image Studio](https://github.com/sanketshinde3001/qwen-image-studio)

A local image-generation and editing studio for **Qwen-Image 2.1**, built to run on a **16 GB Apple Silicon Mac**. Mask editing, 4-step Turbo, version history and 2× / 4× upscaling, with a private mode.

<sub>4-bit GGUF · stable-diffusion.cpp · llama.cpp · Metal · Python</sub>

[Explore repository ↗](https://github.com/sanketshinde3001/qwen-image-studio) · [Get started](https://github.com/sanketshinde3001/qwen-image-studio#getting-started) · [Benchmarks](https://github.com/sanketshinde3001/qwen-image-studio#benchmarks)
